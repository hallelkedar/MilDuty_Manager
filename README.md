# MilDuty_Manager

A Python-based command-line application designed for managing soldier tasks, shifts, and duties. This lightweight management tool provides an organized way to assign, track, and review operational tasks within a military or structured unit environment.

---

## ■ Key Features

* **Soldier & Task Tracking:** Efficiently register soldiers and assign specific operational duties.
* **Status Updates:** Monitor the progress of ongoing tasks and update completion status.
* **CLI Interface:** Clean, text-based terminal interface for fast and direct data input and evaluation.
* **Data Persistence:** Built-in mechanism to save and load records directly within the local environment.

---

## ■ Tech Stack

* **Language:** Python 3.x
* **Modules:** Built using Python standard libraries for high compatibility and zero external dependencies.
